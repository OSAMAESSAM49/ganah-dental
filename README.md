# نظام عيادة جنة لطب الفم والأسنان

برنامج لإدارة العيادة يعمل بالكامل داخل المتصفح. لا يحتاج إلى خادم، ويعمل بدون إنترنت، ويمكن تثبيته على الكمبيوتر أو الموبايل كتطبيق.

> **حالة المشروع:** المرحلة ١ من ١٠ مكتملة: الهيكل، ونظام التصميم، والتخزين، والعمل بدون إنترنت. التفاصيل الكاملة (النشر، والنسخ الاحتياطي، والقيود، ودليل كل دور) ستُضاف في المرحلة ١٠.

## التشغيل على الجهاز

يحتاج البرنامج إلى خادم ملفات بسيط، لأن المتصفح لا يشغّل وحدات JavaScript من ملف مفتوح مباشرة (`file://`).

1. ثبّت [Node.js](https://nodejs.org) (مرة واحدة فقط، ولا يحتاج إلى `npm install`).
2. من مجلد المشروع شغّل:
   ```bash
   node tools/serve.mjs
   ```
3. افتح `http://localhost:5173` في Chrome أو Edge.

لتجربة البرنامج كما سيعمل على GitHub Pages داخل مسار فرعي:
```bash
node tools/serve.mjs --base /ganah-dental/
```

## الاختبارات

افتح `http://localhost:5173/tests/` بعد تشغيل الخادم. الاختبارات تعمل داخل المتصفح ولا تحتاج إلى أي تثبيت.

## بعد تعديل أي ملف

حدّث قائمة ملفات العمل بدون إنترنت؛ بدونها لن تظهر رسالة «يوجد إصدار جديد» على الأجهزة المثبَّت عليها البرنامج:
```bash
node tools/build-asset-list.mjs
```

## الخط

ترخيص خط **ثمانية** لا يسمح برفع ملفاته على موقع، لذلك لا توجد في المستودع:
- على الأجهزة المثبَّت عليها الخط يستخدمه البرنامج تلقائيًا.
- على باقي الأجهزة يظهر خط IBM Plex Sans Arabic (ترخيص مفتوح).
- على iPhone وiPad يظهر دائمًا الخط البديل، لأن Safari لا يسمح باستخدام الخطوط المثبَّتة يدويًا.

## تنبيهات مهمة

- **البيانات محفوظة على الجهاز نفسه فقط** (IndexedDB)، ولا تنتقل بين الأجهزة تلقائيًا. خذ نسخة احتياطية بانتظام (الميزة في المرحلة ٣).
- **تسجيل الدخول داخل المتصفح** (المرحلة ٢) يتحكم في صلاحيات الموظفين، لكنه ليس حماية أمنية حقيقية. الحماية الحقيقية تحتاج إلى خادم، مثل Supabase أو Firebase لاحقًا.
- لا تضع أي بيانات مرضى حقيقية داخل مجلد المشروع أو المستودع.

## هيكل المشروع

```
css/          الألوان والمسافات (tokens.css) والتخطيط والمكوّنات والطباعة
js/core/      التنقل، والتنسيق (العملة والتاريخ والأرقام)، والتحقق، والأيقونات، وهيكل الواجهة
js/data/      طبقة التخزين: IndexedDB، وترحيل المخطط، والمستودعات، والإعدادات
js/components/ مكوّنات قابلة لإعادة الاستخدام: نوافذ، وإشعارات، وجداول، ونماذج
js/modules/   شاشات البرنامج
vendor/       مكتبات وخطوط محفوظة محليًا، وتراخيصها في LICENSES.md
tools/        خادم التطوير ومولّد قائمة ملفات العمل بدون إنترنت
tests/        اختبارات الوحدات داخل المتصفح
docs/         خطة البناء
```
